# 회의록 자동화 봇

회의 녹음 파일을 넣으면 → 텍스트로 바꾸고 → 회의록으로 정리하고 → PDF로 저장해주는 앱이에요.

## 시작하기 전에

컴퓨터에 이 두 가지가 설치되어 있어야 해요.

- **Node.js** (프론트엔드 화면용)
- **Python** (오디오 인식용)

## 사용 방법 (순서대로 따라하면 됨)

### 1단계. 화면 켜기

```
npm install
npm run dev
```

실행 후 브라우저에서 `http://localhost:5173` 접속하면 화면이 뜹니다.

### 2단계. 오디오 인식 서버 켜기

새 터미널 창을 하나 더 열고:

```
cd stt-server
pip install fastapi uvicorn faster-whisper
python -m uvicorn main:app --port 8000
```

### 3단계. mp3 파일 넣기

1. 화면에서 **"파일" 탭** 클릭
2. 주소 입력칸에 `http://localhost:8000/transcribe` 입력
3. **"오디오 파일 선택"**으로 mp3 올리기
4. 텍스트로 변환될 때까지 기다리기 (파일이 길면 시간이 좀 걸려요)

### 4단계. 회의록 만들기

**"회의록으로 정리"** 버튼 클릭 → 자동으로 결정 사항, 할 일, 다음 회의 일정이 정리됩니다.
(별도의 인터넷 API나 키 필요 없이, 이 버튼은 그냥 브라우저 안에서 바로 처리돼요.)

### 5단계. PDF 저장

**"PDF로 저장"** 버튼 클릭하면 완성된 회의록이 PDF로 다운로드됩니다.

## 참고

- 마이크로 바로 말하면서 받아쓰기도 가능해요 ("녹음" 탭, 크롬 브라우저 추천). 이 경우 2단계(오디오 인식 서버)는 필요 없어요.
- mp3 인식 속도는 컴퓨터 성능에 따라 다릅니다. 오래된 컴퓨터는 오래 걸릴 수 있어요.
